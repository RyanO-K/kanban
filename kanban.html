Project Settings

The project's working directory on disk. Agents working this project's tickets operate here.
Agents read this from the project's _meta.json (as commitRequirements) before completing work.
When on, sub-agents isolate code changes in a git worktree (EnterWorktree / git worktree add). When off, they work in place on a branch. Persisted as useWorktrees on _meta.json.
When on, the orchestrator builds a per-repo Docker image and runs the dispatched agent inside a container (workspace mounted at /workspace). Requires Docker on the host and ANTHROPIC_API_KEY in the orchestrator's environment. Persisted as useDocker on _meta.json.
Passed to the container via --env-file (Docker mode). One KEY=VALUE per line; blank lines and # comments are ignored. Stored as envVars on _meta.json — do not put secrets here; forward those from the orchestrator's own environment (e.g. ANTHROPIC_API_KEY) instead.
Names only — the value of each is read from the orchestrator's own environment at dispatch and forwarded with docker run -e NAME. Nothing is ever written to _meta.json, the env-file, or the image. Use this for secrets (GitHub push token, DATABASE_URL, RENDER_API_KEY, Discord token); a listed name absent from the orchestrator env is skipped with a warning in the run log. Anthropic credentials are always forwarded automatically. Stored as passthroughEnv on _meta.json.
